# Super Mario 3D Land (USA): live memory addresses

All addresses below are *live* game data: they change the moment something happens in the game, unlike the save copy at 0x15910850, which only changes when the game saves. Every address was the same in four boots across two days (snapshots from the old plugin and from Azahar's GDB stub, with different saves). Achievement definitions read them with `size 1` unless noted.

## Per save file

| What | File A | File B | File C | Size | Values | Confidence |
|---|---|---|---|---|---|---|
| Lives | `0x1618FAE2` | `0x1618FB42` | `0x1618FBA2` | 2 | count (game caps at 1110) | watched changing in play |
| Star medals collected (total) | `0x1618FAE4` | `0x1618FB44` | `0x1618FBA4` | 2 | count; +1 per course medal, +1 per Mystery Box | matches the save in every snapshot |
| Worlds unlocked | `0x1618FABE` | `0x1618FB1E` | `0x1618FB7E` | 1 (maybe 2) | bitmask, bit 0 = World 1: 1, 3, 7, ... 0xFF; never-started file = 0 | matches the save; only seen up to World 2 |

## Map spots (courses, Mystery Boxes, Toad Houses, castles, airships)

Generated by `python tools/sm3dl_live.py <heap dump>`. For each spot:

- **Status** (u32): 0 = locked, 1 = not beaten, 2 = beaten. Changes as Mario grabs the goal pole (watched for 1-1).
- **Flags** (u32, same as the save record's byte 1): 0x10 = goal reached (set at the pole), 0x08 = shown on the map, bits 0-2 = star medals (0x01 seen with one medal; which bit is which medal is unknown). A beaten course with no medals reads 0x18; with all three, probably 0x1F.
- **Flagpole height** = Status address + 0x0C (u32): 0-100; 100 seen on two courses, probably the top. Set when the course is beaten.
- **Clear time** = Status address + 0x18 (u32): seconds taken (72 matched the timer in one run). Set when the course is beaten.

Special World 8 spot 1 (ChampionshipSpStage) reads status 2 even on a new file, so don't use its status yet.
