# Super Mario 3D Land (USA) - title ID 0004000000054000
#
# Every achievement has one line per save file (A, B, C), so doing it in any
# file unlocks it. All addresses were the same after a reboot.
#
# Live game data (updates the moment something happens), found with Azahar's
# GDB stub. These are what the achievements below use:
#   0x1618FD9C / 0x1619272C / 0x161950BC  1-1 status (files A / B / C):
#            1 = not beaten, 2 = beaten. Part of a list of course records,
#            0x2990 bytes per file; it changed as Mario grabbed the pole.
#   BEAT_WORLD_<n>: the status of each world's last spot (castle, airship or
#            Bowser), same record layout as 1-1. Every spot's address is in
#            docs/sm3dl-live.md (tools/sm3dl_live.py).
#   0x1618FAE2 / 0x1618FB42 / 0x1618FBA2  lives, 2 bytes (files A / B / C),
#            followed by the star medal count. One block per file, 0x60 apart.
#
# The save itself (GameData.bin, all three files) is also in memory, at
# 0x15910850, but it only changes when the game saves. Each file is 0x983
# bytes after the previous one. Save-file offsets (add 0x15910850 for file A):
#   +0x2BF8  map-spot records, 12 bytes each: 1-1, 1-2, first Mystery Box.
#            Byte 0 is the status: 01 = open (also in unused files),
#            02 = beaten. Byte 1 holds per-run flags (star medals).
#   +0x34DF  lives, 2 bytes.
#   +0x2B7B  NOT usable: number of the last spot beaten (went 7 -> 6 when
#            the Toad House was beaten after the castle).
#
