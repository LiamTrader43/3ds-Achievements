# The Legend of Zelda: Ocarina of Time 3D (USA) - title ID 0004000000033500
#
# A port of the RetroAchievements set for the original Ocarina of Time (N64):
# same names, descriptions and points, conditions rewritten for OoT3D's memory.
# Group 1 so far: achievements read straight from the save data.
#
# OoT3D keeps the loaded save file at 0x587958 (gSaveContext, 0x15C4 bytes; the
# save file on the SD card is the same bytes, RAM = file offset + 0x587958).
# Layout from the OoT3D randomizer's z3D.h and the OcarinaCTRComposer RAM map:
#   0x5879E4  items[26], one byte per slot, 0xFF = empty (3 Bow, 4 Fire Arrow,
#             5 Din's Fire, 8 Bombchu, 9 Hookshot, 11 Farore's Wind, 13 Lens,
#             14 Magic Beans, 17 Nayru's Love, 18-21 Bottles)
#   0x587A0E  equipment, u16: swords 0-3 (2 = Giant's Knife/Biggoron's Sword),
#             shields 4-6, tunics 8-10 (Goron 9, Zora 10), boots 12-14 (Iron 13)
#   0x587A10  upgrades, u32: strength = bits 6-8 (1 bracelet, 2 silver, 3 gold)
#   0x587A14  quest items, u32: medallions 0-5 (Forest, Fire, Water, Spirit,
#             Shadow, Light), songs 6-17, stones 18-20 (Emerald, Ruby,
#             Sapphire), Gerudo card 22
#   0x58799A  max health, u16 (16 per heart; 320 = 20 hearts)
#   0x5879A6  magic acquired; 0x5879A9 double defense; 0x5879AA Biggoron's
#             Sword flag (1 = the unbreakable sword, 0 = Giant's Knife)
#   0x58795C  Link's age, s32 (0 adult, 1 child)
#   0x588844  eventChkInf[14], u16 each: N64 decomp flag 0xAB = word A, bit B
#             (e.g. 0x45 obtained the Master Sword = 0x58884C bit 5)
#
# Checked against three real saves: a new file (nothing unlocks), and two 100%
# saves from GBAtemp (US and EU: everything unlocks); none unlock on the title
# screen.
#
# Every condition starts with "a file is really loaded": gameMode (0x588E3C,
# s32) = 0 (normal play) and fileNum (0x588E34, s32) < 3. The title screen and
# file select hold a debug save (adult Link, 14 hearts, every medallion, song,
# tunic, boot and nearly every item) with gameMode 1 (title) / 2 (file select)
# and fileNum 0; gameMode turns 0 at the moment the real file is in memory.
# (Seen live in Azahar, 2026-11-05.) gameMode must also have been 0 on the last
# poll (d0xX588e3c=0): on the poll the file appears, every "d" value still holds
# the debug save, so a change-based condition would see the debug save turning
# into the file as an event (A Horrible Face unlocked that way in a replay).
#
# The game's live state (GlobalContext: current scene, actor lists, room flags)
# is read through the game's own pointer to it, u32 0x58B2E0: such a condition has
# I:0xX58b2e0_ in front and an offset into GlobalContext as its address. The game
# doesn't always put GlobalContext at the same address: on its first launch (no
# save data yet) the USA game has it at 0x0874A5F0 instead of 0x0871E840 for the
# whole session, and the EUR/JPN releases have it elsewhere too; 0x58B2E0 follows
# it in all of them. (Found 2026-11-11 on a 3DS and in Azahar.)
#
# rcheevos bit sizes: 0xM = bit 0 ... 0xT = bit 7 of a byte.
#

# Live GlobalContext data (offsets, read through 0x58B2E0): scene s16 +0x104; actor
# lists at +0x2098 + 8*category {u32 count, Actor* head} (player head +0x20AC, enemy
# head +0x20C4, boss count +0x20E0 / head +0x20E4; new actors are added at the
# head); lens active u8 +0x208F; room clear flags u32 +0x223C; cutscene state u8
# +0x22A0. Actor: y float +0x2C, depth in water float +0x88, health u8
# +0xB7, id u16 +0. Link (player actor): held item action s8 +0x1A9 (N64
# PLAYER_IA_*), stateFlags1 +0x1710 (bit 23 riding), stateFlags2 +0x1714 (bit 7 held
# by Morpha's tentacle / Bongo Bongo's hands).
# A dungeon boss is beaten when its room's clear flag rises (each boss sets it as the
# blue warp appears) while a boss actor existed on the previous poll (not on re-entry;
# Azahar: Gohma and King Dodongo stay in the boss list through it). OoT3D actor ids
# can differ from N64's: King Dodongo is 0x12 (N64 0x27); Gohma 0x28 matches.
# Ganondorf is beaten when the entrance (s32 0x587958) becomes 0x43F (tower collapse),
# Ganon when it becomes 0x06B (Chamber of the Sages) straight from his scene (0x4F).
# A try starts when Link arrives in the boss scene; breaking a rule (ResetIf) ends it
# until he comes back. Rules only apply after the scene's first poll (loading).
# Approximations: Spider Net = Gohma landed at full health (10) and never climbed back
# above y -560 before dying (Azahar: right); KD's fire breath = 2+ actors in the enemy
# list (Azahar: the breath spawns up to 27 flames, id 0; charging it is 1 actor);
# Drunken Master = Phantom Ganon at 1-2 HP (non-sword hits stop at 2); Race Against
# the Clock counts 111 s of non-cutscene time in the room; lens = the lens flag;
# Twinrova fall = Link drops from y >= 200 to below 200 between polls (platform 240;
# Azahar: he enters the arena at y 0 and rides up); Ganondorf fall = drops below y -150 (a ledge grab reads about -65; the room's lowest floor is -740).
# Lifestyle and Stones: the current message id is u16 0x5C27B8 (Azahar: 0x2054, then the
# rumor 0x400 + (stone params & 0xFF)); rumors 0x401-0x420, hits reset on the title screen.

# while all three rocks of the top-floor blockade (switch flags 3, 9, 10) are intact; the
# boulders inside the maze don't matter. Link's actor must exist on both polls, so flags
# being loaded with the scene don't count as a chest being opened.
